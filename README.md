# K-Beauty Wiki

日本のユーザー向けに、韓国コスメとスキンケアの情報をわかりやすく整理するK-ビューティー情報Wikiです。

## 概要

ブランドや成分、肌悩み、使い方などの情報を、日本語で検索・比較しやすい形で提供することを目指します。

## 開発状況

現在はプロダクトの土台を整えている段階です。今後、情報設計と画面実装、データベース連携を順番に追加していきます。

## 主な機能（予定）

- 韓国コスメ・スキンケア情報の検索
- ブランド、商品、成分、肌悩みによる分類
- 商品ごとの特徴、使用方法、対象肌質の表示
- 日本語を基本とした読みやすい情報ページ
- モバイルとデスクトップに対応したレスポンシブUI
- 情報の更新履歴と出典の管理

## 技術スタック

- Next.js
- TypeScript（strict）
- Tailwind CSS
- PostgreSQL
- pnpm

## 開発環境

### 必要なもの

- Node.js
- pnpm
- PostgreSQL

### セットアップ

```bash
pnpm install
pnpm dev
```

開発サーバーは通常 `http://localhost:3000` で起動します。

### 環境変数

ローカルの `.env.local` に PostgreSQL の接続情報を設定します。

```env
DATABASE_URL="postgresql://ユーザー名:パスワード@localhost:5432/k_beauty_wiki"
```

`.env.local` などの秘密情報を含むファイルはコミットしないでください。

## コマンド

```bash
# 開発サーバー
pnpm dev

# Lint
pnpm lint

# テスト
pnpm test
```

## 開発方針

- 日本語を基本言語とする
- モバイルとデスクトップの両方で使いやすいUIを設計する
- TypeScript の strict 設定を維持する
- 新しいライブラリの追加は必要最小限にする
- 美容情報は出典と更新日を意識して管理する
- 変更ごとに関連するLintとテストを実行する
