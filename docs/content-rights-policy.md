# 콘텐츠 출처·권리 운영 정책

이 문서는 K-Beauty Atlas Japan의 MVP 콘텐츠를 공개하기 위한 내부 운영 기준이다. 법률 자문을 대체하지 않으며, 출처 사이트의 최신 약관과 실제 이용 방식은 공개 전 다시 확인한다.

## 기본 원칙

- 원문 전체를 복사하지 않는다.
- 출처 URL, 출처 제목, 확인일, 수집 방식을 기록한다.
- 자동 수집은 공식 API, 서면 허가, 또는 명확하게 허용된 방식으로만 한다.
- 허용 여부가 불명확하거나 약관이 자동 수집을 금지하면 `prohibited`로 분류하고 수집하지 않는다.
- 커뮤니티 경험담은 의학적 사실이나 객관적인 순위가 아닌 참고 지표로 표시한다.
- 리뷰 원문 대신 여러 출처에서 반복된 의견을 요약한다. 원문 인용이 필요하면 필요한 최소한의 짧은 인용과 원문 링크만 사용한다.
- 닉네임, 프로필, 사진, 연락처, 건강·시술 이력 등 개인 식별 가능 정보는 저장하지 않는다.

## 출처 상태

| 상태 | 사용 기준 |
| --- | --- |
| `verified` | 공식 API, 유효한 서면 허가, 또는 사용 범위가 확인된 라이선스 |
| `reference-only` | 원문을 복제하지 않고 링크와 요약 근거로만 사용 |
| `needs-review` | 관리자 또는 권리 검토 전에는 공개 금지 |
| `rejected` | 약관 위반, 권리 불명확, 삭제 요청 등으로 사용 금지 |

`published` 콘텐츠에는 모든 출처가 `verified` 또는 `reference-only`여야 한다. `prohibited`, `needs-review`, `rejected` 출처가 하나라도 있으면 공개하지 않는다.

## 커뮤니티 리뷰 집계

- 커뮤니티 신호를 표시하려면 표본 5건 이상을 사용한다.
- 가능하면 서로 다른 게시글·출처를 포함하고, 하나의 게시글이 전체 평가를 결정하지 않게 한다.
- 표본 수, 수집일, 출처 링크, 요약 방법을 기록한다.
- “대부분”, “효과가 보장된다”처럼 표본을 넘어서는 표현을 쓰지 않는다.
- 의료 시술의 효과·부작용은 커뮤니티 경험담만으로 단정하지 않는다.

## 권리침해·정정 요청

권리자 또는 이용자가 정정·삭제를 요청하면 요청 URL, `requestType`(정정 또는 권리침해), 문제 유형, 접수일, 처리 상태, 처리 결과를 기록한다. 확인 전에는 해당 콘텐츠를 비공개 또는 검수 상태로 전환할 수 있어야 한다.

## 우리 사이트의 콘텐츠 라이선스

MVP의 편집 콘텐츠는 별도 라이선스를 표시하지 않는 한 K-Beauty Atlas Japan의 저작물로 관리한다. 외부 위키 문서나 커뮤니티 문서를 번역·재작성하여 우리 콘텐츠로 등록하지 않는다. 공개 라이선스 콘텐츠를 사용할 때는 원 라이선스와 출처를 개별적으로 기록하고, 라이선스 조건이 상충하면 사용하지 않는다.
