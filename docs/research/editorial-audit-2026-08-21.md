# Editorial audit — 2026-08-21

## 범위

`docs/research/*.review.json`에 있는 출처 기반 콘텐츠 초안 16개를 자동 편집 감사했다.

실행 명령:

```text
pnpm audit:editorial
```

## 결과

| 항목 | 결과 |
| --- | ---: |
| 감사 대상 | 16 |
| 구조 검증 통과 | 16 |
| 자동 공개 필드 검증 통과 | 16 |
| 수동 편집 승인 필요 | 16 |
| 공개 허용 | 0 |
| 자동 검사 차단 | 0 |

모든 초안은 필수 필드, 출처, 확인일을 갖추고 있어 자동 필드 검사를 통과했다. 그러나 모든 초안의 상태가 `review`이므로 자동 감사만으로 공개하지 않는다.

## 공개 차단 기준

- `review` 상태를 유지하고 관리자 또는 편집자의 명시적인 공개 승인을 받지 않는다.
- 모든 출처는 `reference-only`로 기록되어 있으며, 출처의 상품 이미지나 이용자 리뷰를 복사·수집하지 않았다.
- 가격, 재고, 패키지 표시, 사용상 주의사항은 확인일과 판매 조건에 따라 다시 확인한다.
- 성분·브랜드 문구만으로 발색, 지속성, 안전성, 피부 적합성을 독자적으로 결론내리지 않는다.
- 공개 전에는 일본어 문장, 한국어 원명, 출처 URL, 최종 확인일, 면책 문구를 사람이 다시 검토한다.

## 다음 단계

1. 관리자 화면에서 후보별 출처와 필수 필드를 확인한다.
2. 편집자가 공개 승인 여부와 승인 메모를 남긴다.
3. 승인된 항목만 `published`로 전환하고 공개 사이트와 sitemap에 노출한다.
4. 승인되지 않은 항목은 계속 `review`로 유지한다.
